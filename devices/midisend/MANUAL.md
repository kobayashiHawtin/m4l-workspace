# midisend — 取扱説明書

**midisend** は、このトラックの MIDI ノートを**バス経由で別のデバイスへ送る** Max for Live MIDI エフェクトです。`midimerge` とペアで使い、2つのトラックのフレーズ（A/B）を1つの音源で混ぜるための**送信側**です。

## セットアップ

1. **送りたいトラック（B）** に `midisend` を挿します。
2. **BUS** を 1〜8 のいずれかに合わせます。同じ番号の `midimerge` だけがこのノートを受信します。
3. **`MIDI To` は設定しないでください**（`No Output` のまま）。Live 標準のルーティングで B を A へ送ると、モーフを迂回して B が常に鳴ります。
4. ノートは **`noteout` にもそのまま通ります**。B トラック自身の音を鳴らしたくない場合は、B をミュートするか音源を外してください。

```
[Track B] notes ─▶ [ midisend ] ─▶ noteout（B の音源・任意）
                        │
                        └─ bus: midimerge_<BUS> ─▶ [ midimerge ]（A トラック）
```

## パラメータ

| パラメータ | 範囲 / 初期値 | 説明 |
| --- | --- | --- |
| **BUS** | 1–8 / `1` | 送信先のバス番号です。同じ番号の `midimerge` とペアになります。 |

## 動作

- ノートオン／オフとベロシティをパックして、バスへ送ります。
- バス名は実行時に `midimerge_<BUS>` として組み立てられます（`[forward]` を使用。`[send]` は作成後に改名できないため）。
- バスはグローバル名なので、Live の `MIDI To`（`---` で個別名になる）と違い、離れたトラック間でも確実に届きます。

## 注意・制限

- 受信側は `midimerge` を想定しています（バス名 `midimerge_<BUS>`）。
- BUS を変えたときは、ペアの `midimerge` も同じ番号にしてください。
- ノートは `noteout` にも通るため、B の音を二重に鳴らしたくない場合は B をミュートします。
