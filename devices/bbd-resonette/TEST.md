# bbd-resonette — test procedure

`instrument`: MIDI notes arrive on `notein`, audio leaves on `plugout~`. The
sound is a **6-voice polyphonic Karplus-Strong resonator**: notes go through
`midiformat` -> `mc.noteallocator~` (voice allocation) -> `mc.target` and drive
one `mc.gen~ @chans 6` core, where each voice has its own feedback delay whose
length tracks the played pitch. The exciter is an MC chain (the **Osc**
`mc.gen~` — a 5-wave oscillator morphed by WAVE — plus `mc.noise~`, blended by
EXCITE) shaped by a per-voice **DADSR** envelope (a second `mc.gen~ @chans 6`
whose Gen `codebox` runs the state machine) and filtered by `mc.onepole~`.
Because the delay runs inside `gen~` (one sample at a time) the whole keyboard
range tunes — `tapin~`/`tapout~` is capped at ~F5 by the signal vector size.

Per-voice control uses `mc.target`: the voice number from `mc.noteallocator~`
lands in its right inlet, so a note's value becomes `setvalue <voice> <value>`.
`setvalue 0` would broadcast to *all* voices, which is why the voice number must
come from `mc.noteallocator~` (its voices are non-zero), and why `mc.sig~` (which
does not accept `setvalue`) is not used to hold the pitch.

The face reads left to right in signal order: **EXCITER** (**WAVE** morph display
on top, with the **EXCITE** / **FILTER** dials below it), **ENVELOPE** (the
`live.adsrui` DADSR editor, with **ONSET** below it and a small **LOOP** button
in its top-right corner), and **RESONATOR** (**RING** / **DAMP** / **MIX**
dials in a row inside a grouped panel, with an **INVERT** button, a 3-way
**DECAY MODE** tab (TIME / TIME+DAMP / FBACK) and a micro **LEVEL** trim in a
control bar below them).
Drag the `live.adsrui` handles to shape the exciter envelope (double-click
resets). **WAVE** is a `jsui` strip: drag it to morph the oscillator
sine → triangle → saw → 5% pulse → square (the current waveform is drawn inside).
EXCITE blends noise (0) <-> the shaped tone (1). FILTER is the exciter low-pass
(100 Hz .. 18 kHz), EXC LEVEL is the exciter output into the BBD (drive the
resonator harder -> louder / grit). RING is the resonator decay (0.05 .. 20 s
in TIME / TIME+DAMP; a raw feedback amount in FBACK), DAMP the resonator
damping, MIX dry/wet (**100 % wet = the recirculating ring only** — the direct
exciter pass is cancelled, so the exciter really disappears at 100 %), LEVEL the
output gain, ONSET the envelope delay.
**INVERT** flips the loop polarity, **DECAY MODE** selects how RING maps to the
loop gain (see below), and **LOOP** re-fires the envelope while the note is held.

Decay modes (RING):
- **TIME** — RING is the **exact t60 at every pitch**, up to a stability cap: the
  linear loop runs closest to unity here, where the BBD sample-and-hold folds its
  own images back onto f0 and adds a pitch-dependent gain, so the loop gain is
  capped (≈ 0.99) and very long RING settings clamp at high notes
  (≈ 690/f0 s: ~6 s at 110 Hz, ~3 s at 220 Hz). DAMP darkens the tone statically.
- **TIME+DAMP** — same RING *target*, but the loop filters stay in the loop, so
  high notes decay faster than low notes and DAMP darkens progressively as the
  note rings. The audible t60 is therefore shorter than RING at any pitched f0.
- **FBACK** — RING is a raw loop feedback amount (not seconds): low notes ring
  longer than high notes, and the top of the range rings the longest.

The face has **two pages**, switched by the small **MAIN | PITCH** tab at the
bottom right. **MAIN** is the layout above. **PITCH** holds the exciter's own
tuning controls: **KEY FOLLOW** (0..100 %), **COARSE** (+/-4 octaves), **FINE**
(+/-3 semitones) and the **KB RESET** toggle (restart the oscillator phase on
each note-on). The **resonator always tracks the played key** — only the
exciter's pitch can be detached — so the resonator stays the pitch-defining
element (see ECHON6-GAP 3.26).

Every dial's Live parameter now carries its **real** value and native Live Unit
Style (FILTER = Hertz, RING / ENV TIME = Time, MIX = %, LEVEL = deciBel), so the
automation / MIDI-map list reads in musical units; the small readout under each
dial shows the value with its unit (e.g. `3.25kHz`, `1.86s`, `-2.1dB`, `87%`).

> **The WAVE control is a `jsui` object that loads `bbd_wave.js`.** That file
> must sit next to the patch/device (it is generated by the build). The `.amxd`
> does not embed it.

The ENVELOPE shape (dly / atk / dcy / sus / rls / peak) is stored in six hidden
`live.dial` parameters (Env Delay / Env Attack / Env Decay / Env Sustain /
Env Release / Env Peak), so it is saved in Live presets and the Live set. The
editor redraws from those parameters when a preset is recalled.

## Generate

```
python bin/dev.py generate bbd-resonette     # generate + lint + wrap .amxd
python bin/dev.py status bbd-resonette
```

or, manually (maxpylang venv active):

```
python devices/bbd-resonette/generate.py
python bin/lint-patch.py devices/bbd-resonette/bbd-resonette.maxpat \
                         devices/bbd-resonette/bbd-resonette_test.maxpat
python bin/maxpat-to-amxd.py devices/bbd-resonette/bbd-resonette.maxpat \
                             devices/bbd-resonette/bbd-resonette.amxd \
                             --type instrument
```

## Max-only (`bbd-resonette_test.maxpat`) — opens in presentation mode

The test patch replaces `notein` / `plugout~` with a `kslider` + `makenote` (and
a `PLAY CHORD` button) and an `ezdac~`.

1. Open `devices/bbd-resonette/bbd-resonette_test.maxpat`.
2. **PLAY CHORD** plays C-E-G (60/64/67) and releases after 2 s — you should
   hear a real 3-note chord (polyphony), not one note.
3. **AUDIO** toggle = output on/off (on by default).
4. Click the **kslider** for single notes.
5. **WAVE** — drag the knob up/down: the tone glides sine (bottom) → triangle
   → saw → 5% pulse → square (top). Shift-drag for fine steps; double-click
   resets to sine. The knob redraws the waveform and its name as you drag.
6. **EXCITE** 0 = noise (percussive, airy), 1 = the shaped tone (bowed / flute).
7. Drag the **ENVELOPE** handles to shape the exciter DADSR (attack / decay /
   sustain / release / peak). The active handle enlarges; double-click resets
   the shape. **ONSET** sets a pre-attack delay (0 ms .. 1 s). **LOOP**
   (a toggle in the ENVELOPE header) repeats the contour while the note is held
   (a repeating bow).
8. **RING** sets the resonator decay (0.05..20 s in **TIME** / **TIME+DAMP**,
   or a raw feedback amount in **FBACK**). In **TIME** the same setting rings for
   the same length across the keyboard; **TIME+DAMP** keeps the loop filters so
   high notes ring shorter; **FBACK** makes low notes ring longer. **DAMP**
   darkens the ring.
9. **FILTER** is the exciter low-pass (100 Hz .. 18 kHz, shown in kHz); **EXC
   LEVEL** is the exciter output into the resonator (0..100 %; push it up to
   drive the BBD harder — louder and grittier); **MIX** blends the dry exciter →
   the wet **recirculating ring** (0..100 %; 100 % removes the exciter — a parallel
   input-only delay subtracts its straight-through pass, so the wet is the ring
   the resonator adds, not the input again); **LEVEL** is the output (-70..6 dB,
   0 dB = unity). The **DECAY MODE** tab (TIME / TIME+DAMP / FBACK) sits next to
   **INVERT**.
10. **INVERT** (a toggle in the ENVELOPE header) flips the feedback-loop polarity.
    Inverting a tuned feedback comb shifts every resonance by half the comb
    spacing, so the played note becomes a notch and the sub-octave (f0/2) rings
    instead: the tone turns hollow and the pitch sensation drops. It is not a
    subtle phase tweak (`polarity`); OFF is the normal in-phase loop.
11. Sweep the `kslider` across the keyboard — the pitch should track all the way
    up (no ceiling at ~F5), and the resonator should sit **in tune** with the
    key (the retune compensates the loop filters, the sample-and-hold's half
    clock period and the 1-sample history).
12. Switch to the **PITCH** page (the small **MAIN | PITCH** tab, bottom right).
    **KEY FOLLOW** = 100 % makes the exciter track the key (chord C-E-G →
    261 / 329 / 392 Hz). Pull **KEY FOLLOW** down to 0 %: the exciter freezes on
    a single pitch (C4, offset by **COARSE** / **FINE**) while the **RESONATOR
    keeps tracking** — i.e. only the exciter detaches, the resonator stays the
    pitch-defining element. **COARSE** shifts it in octaves, **FINE** in
    semitones (set them apart from the resonator to hear beating). **KB RESET**
    restarts the oscillator phase on every note-on.

## Live (`.amxd`)

> Live caches the device UI. After regenerating, **remove and re-add** the
> device from the track — reloading the file is not enough. Keep `bbd_wave.js`
> and `bbd_env.js` beside the `.amxd`.

1. Drag `devices/bbd-resonette/bbd-resonette.amxd` onto a **MIDI track**.
2. Play notes — each note plucks/bows a resonator at its own pitch, and chords
   ring as separate voices.
3. Automate / MIDI-map: EXCITE, FILTER (Hz), RING (s), DAMP, MIX (%), LEVEL
   (dB), **EXC LEVEL (%)**, ONSET (ms), Wave, **Resonator Feedback (%)** (only
   used in FBACK), Env Delay / Attack / Decay / Sustain / Release / Peak,
   Exciter Key Follow (%), Exciter Coarse (oct), Exciter Fine (st), and the
   INVERT / LOOP / EXC LEVEL / **Decay Mode** (TIME / TIME+DAMP / FBACK) / Key
   Reset controls. (EXC LEVEL and Resonator Feedback are automatable **hidden**
   parameters for now — their face knobs come in the UI pass.)
4. Drag **WAVE** for the oscillator timbre, the **ENVELOPE** shape for plucks vs
   drones; enable **LOOP** for a repeating bow. Save a preset and confirm the
   envelope shape is recalled.

## Known limitations

- **6 voices**. Overlapping notes beyond six steal the oldest voice. A voice
  stays busy for the **whole ring**, so a long **RING** holds voices longer and
  lowers the effective polyphony (the ring is no longer cut at the exciter
  release).
- **RING**/**DAMP** at the extreme give a very long, loud, dense ring; it is bounded
  by the loop-gain cap (and, in TIME, its ~0.99 stability cap), so the resonator
  does not run away.
- **DECAY MODE** selects how RING maps to the loop gain. **TIME (default)**
  makes **RING the exact decay time (t60) at every pitch** and DAMP darkens the
  tone statically. The saturator lives on the **output** stage, not in the loop:
  an in-loop nonlinearity made the BBD sample-and-hold alias its harmonics,
  which capped the ring at a couple of seconds for any long RING. Because TIME's
  loop then runs close to unity, its gain is capped (~0.99) for stability, so a
  very long RING **clamps at high notes** (≈ 690/f0 s). **TIME+DAMP** keeps the
  loop filters, so high notes decay faster than low notes and DAMP darkens
  progressively (the audible t60 is then shorter than RING). **FBACK** turns RING
  into a raw feedback amount: low notes ring longer than high notes. All are
  DC-safe (no runaway, no low-frequency resonance), and no mode self-oscillates.
- **MIX = 100 % wet is the recirculating ring only.** A delay-line resonator
  otherwise passes its input straight through, delayed by exactly one period —
  which sounds like the original exciter and makes the dry/wet feel broken. A
  parallel input-only delay subtracts that straight-through pass, so 100 % wet
  removes the exciter (exact in the linear region; the loop compander / output
  saturation leave a trace).
- Every control carries a bilingual (EN/JA) **Info View** text (the Live
  `Annotation Name` + `Annotation`), so hover a parameter to read what it does.
- **INVERT** is a polarity switch on the feedback loop, not a separate mode. It
  moves the comb against the played pitch (notch at f0, sub-octave resonance),
  so it reads as a big timbre/pitch change rather than a gentle phase shift.
- The **WAVE** `jsui` control requires **`bbd_wave.js`** next to the device
  (not embedded in the `.amxd`).
- The ENVELOPE editor is a fixed-width view: the four segment lengths
  (dly / atk / dcy / rls) are stored independently, but the drawn x-axis clamps
  their cumulative position to the panel, so a shape whose segments sum to more
  than 1 is drawn compressed (the engine still uses the stored times).
- The `mc.gen~` cores (resonator, envelope, oscillator) are embedded in the
  `.maxpat` (no external `.gendsp`), so the audio side is self-contained.
- No MPE / per-voice pan yet; both channels are the collapsed MC mix.
