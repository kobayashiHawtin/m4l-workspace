# bbd-resonette — 取扱説明書

**bbd-resonette** は、**6声ポリフォニック**の Karplus-Strong／BBD（バケット・ブリゲード）系**レゾネータ・シンセ**（Max for Live **インストゥルメント**）です。MIDI ノートを受け取り、各ノートをその音程に追従するチューニング済みの共鳴体で「弾く／こする」ような音にします。撥弦からドローンまで、エキサイタ（励振源）とレゾネータ（共鳴体）を別々に作り込めます。

## セットアップ

1. **MIDI トラック**に `bbd-resonette.amxd` をドロップします。ノートを弾くと音が出ます。
2. **`bbd_wave.js` と `bbd_env.js` を `.amxd` の隣に置いてください。** WAVE コントロール（`jsui`）が読み込む外部ファイルで、`.amxd` には埋め込まれていません（ビルドが生成します）。
3. Live はデバイス UI をキャッシュします。再生成後は**削除→再追加**してください。

## フェイス

音の信号順（左→右）に並んでいます。

- **EXCITER** — **WAVE**（波形モーフ、上）と **EXCITE** / **FILTER**（下）。
- **ENVELOPE** — **DADSR エディタ**（`live.adsrui`）と、その下の **ONSET**、右上の **LOOP**。
- **RESONATOR** — **RING** / **DAMP** / **MIX**（グループ内）、下のコントロールバーに **INVERT** / **CHAR** と **LEVEL**。

右上の **MAIN | PITCH** タブで**2ページ**を切り替えます。**PITCH** ページはエキサイタ側のチューニング（**KEY FOLLOW / COARSE / FINE / KB RESET**）です。

## パラメータ

| パラメータ | 範囲 / 初期値 | 説明 |
| --- | --- | --- |
| **WAVE** | sine→tri→saw→5%pulse→square / `sine` | エキサイタ波形のモーフです。ドラッグで変化、ダブルクリックで sine に戻ります。 |
| **EXCITE** | 0–1 / `0.50` | 0 = ノイズ（打楽器・空気感）、1 = 波形トーン（弓・フルート）。 |
| **FILTER** | 100 Hz–18 kHz / `3250 Hz` | エキサイタのローパスです（Hz）。 |
| **RING** | 50 ms–6 s（t60 0.05–6 s）/ `1860 ms` | 共鳴体の減衰時間です。 |
| **DAMP** | 0–0.95 / `0.48` | 共鳴体の減衰（暗さ）です。CHAR により働き方が変わります。 |
| **MIX** | 0–100 % / `87%` | 乾いたエキサイタ → 湿った共鳴体のブレンドです。 |
| **LEVEL** | -70〜+6 dB / `-2.1 dB` | 出力レベルです（0 dB = unity）。 |
| **ONSET** | 0–200 ms / `0` | エンベロープ開始前の遅延です。 |
| **KEY FOLLOW** | 0–100 % / `100` | エキサイタの**キーボード追従の深さ**です（100 = 弾いた音程に追従）。 |
| **COARSE** | -4〜+4 oct / `0` | エキサイタを共鳴体に対してオクターブ単位でデチューンします。 |
| **FINE** | -3〜+3 st / `0` | エキサイタを半音単位でデチューンします（うなり／モアレ）。 |
| **INVERT** | on/off / `off` | ループ極性を反転します（下記）。 |
| **CHAR** | FLAT / STRING / `STRING` | 共鳴体のキャラクタです（下記）。 |
| **LOOP** | on/off / `off` | ノートを保持している間、エンベロープを繰り返します（繰り返す弓）。 |
| **KB RESET** | on/off / `off` | ノートオンごとにオシレータ位相をリセットします。 |

**ENVELOPE エディタ** — `live.adsrui` のハンドルをドラッグしてエキサイタの DADSR（delay / attack / decay / sustain / release / peak）を直接ミリ秒で作ります。アクティブなハンドルは拡大表示され、ダブルクリックで初期形に戻ります。形は隠しパラメータとして保存され、Live のプリセットに追従します。

## 使い方・レシピ

- **撥弦（pluck）**: `EXCITE 0.6`・短い ATTACK・短い DECAY・`RING 1.5s`。弦を弾いたような減衰になります。
- **弓／ドローン（bow / drone）**: `EXCITE 1.0`・長い SUSTAIN・`LOOP on`。保持中ずっと鳴り続けます。
- **共鳴体を強調**: `MIX` を上げ、`DAMP` を下げて長い余韻にします。
- **うなりを作る**: `COARSE` / `FINE` を 0 から少しずらし、エキサイタを共鳴体からデチューンします。
- **中空の音**: `INVERT on`（下記）。

## しくみ（要点）

- 音程を決めるのは**共鳴体**で、常に弾いた鍵に追従します。デタッチできるのは**エキサイタの音程だけ**です（KEY FOLLOW / COARSE / FINE）。
- 遅延は `gen~` 内で1サンプルずつ回るため、鍵盤全域で音程が合います。
- エキサイタは WAVE でモーフするオシレータとノイズを EXCITE で混ぜ、DADSR で整形し、ローパスを通したものです。

## 注意・制限

- **6声**です。重なったノートは最も古い声を奪います。声は**余韻（RING）の間ずっと**使われるため、RING を長くすると同時発音数が実質的に減ります。
- **INVERT** はループ極性の反転です。チューニングされたフィードバック・コムでは、反転すると共鳴が半コム分ずれ、弾いた音程がノッチになって**サブオクターブ（f0/2）**が鳴ります（中空で、音程感が下がります）。軽い位相変化ではありません。
- **CHAR = STRING**（既定）はループフィルタを残すため、高い音ほど早く減衰し、DAMP が進行的に暗くします。**CHAR = FLAT** はループ損失を平坦化し、**全音程で RING が厳密な減衰時間（t60）**になり、DAMP は静的に音色を暗くします。どちらも暴走・低域共鳴しません。
- **WAVE** は `bbd_wave.js` が `.amxd` の隣に必要です（埋め込みではありません）。
- ENVELOPE エディタは固定幅表示です。4区間の長さは個別に保存されますが、表示上は合計がパネルを超えると圧縮して描かれます（エンジンは保存値をそのまま使います）。
- MPE / 声ごとのパンには未対応です（2ch は MC ミックスの縮約）。
