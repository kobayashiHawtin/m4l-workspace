# echomod — 取扱説明書

**echomod** は、**オーディオを素通ししたまま**、LFO またはエンベロープ・フォロワーの信号を作り、**ディレイを通して最大8個の Live パラメータを変調する** Max for Live オーディオエフェクト（マッピング・モジュレータ）です。Live 標準の LFO／Envelope Follower と同じ位置づけで、変調そのものに「エコー」をかけられるのが特徴です。

## セットアップ

1. 変調したいデバイスと**同じトラック**（または同じ Rack 内）に `echomod` を挿します。オーディオはそのまま通ります。
2. **Page = Map** を開き、各行の **Map** をクリック → 変調したい Live パラメータをクリックして割り当てます。
3. 変調が動いているのが聴こえる／見える状態になります。

```
audio in ─▶（素通し）─▶ audio out
              ↑
  LFO / Envelope ─▶ mod-delay ─▶ live.modulate~ ×8 ─▶ マップした Live パラメータ
```

## パラメータ

| パラメータ | 範囲 / 初期値 | 説明 |
| --- | --- | --- |
| **RATE** | 0–127 / `6` | LFO の速さです（Hz、SYNC 中は音符分割）。SOURCE=Env のときは **RISE**（立ち上がり ms）になります。 |
| **SHAPE** | 1–4 / `1` | LFO 波形です（1 sine / 2 tri / 3 saw / 4 square）。SOURCE=Env のときは **FALL**（減衰 ms）になります。 |
| **TIME** | 0–127 / `16` | 変調ディレイの時間です（ms、SYNC 中は音符分割）。 |
| **FEEDBACK** | 0–0.95 / `0.52` | 変調ディレイのフィードバック量です。高いと自己発振しますがクリップで上限が付きます。 |
| **MIX** | 0–1 / `0.5` | 乾いた変調 ↔ ディレイした変調をクロスフェードします（音量ノブではありません）。 |
| **GAIN** | 0–4 / `0.5` | **エンベロープ検出器に入る信号の量**だけを変えます。出力音量は変わりません（小さい音源は上げ、大きい音源は下げる）。 |
| **FREQ** | 20 Hz–20 kHz / `C3` 相当 | 検出器の EQ の周波数です。Tilt では支点、Band では中心。 |
| **Q** | 0.02–0.9 / 中央 | Band モードのバンドパス幅です。 |
| **TILT** | -12〜+12 dB / `0` | Tilt モードの傾きです（高い方を上げ、低い方を下げる）。 |
| **SYNC** | on/off / `off` | on で LFO とディレイを Live のトランスポートに同期します。 |
| **SOURCE** | LFO / Env / `LFO` | 変調源を選びます。Env で RATE/SHAPE が RISE/FALL に切り替わります。 |
| **SIDECHAIN** | Int SC / Ext SC / `Int SC` | 検出器に入れる信号を、内部（このトラック）か外部サイドチェインから選びます。 |
| **EQ MODE** | Tilt / Band / `Tilt` | 検出器 EQ の方式です。 |
| **PAGE** | Main / Det / Map / `Main` | フェイスのページを切り替えます。 |

## フェイスのページ

- **Main** — SOURCE（LFO / Env）と変調ディレイです。SOURCE=Env のときは RATE/SHAPE が **RISE / FALL** の表示に変わります。
- **Det** — 検出器の設定です。**SC SOURCE / CHANNEL**（サイドチェイン）と **FREQ / Q / TILT / EQ MODE**、そして検出器の Direct／S.C. レベルメーターがあります。
- **Map** — 8行のマッピングです（下記）。

## マッピング（Map ページ）

1. 各行は `N | Map | x | Range | bar` です。
2. 行の **Map** をクリックし、続けて Live のパラメータをクリックすると、その名前が Map ボタンに表示されます。
3. 行の **x** はその行だけ解除、ヘッダの **x（Clear）** は全行を解除します。
4. **Range**（-100〜+100）は変調の深さです。常にバイポーラで、符号は位相を反転させるだけです。隣のバーは Range の値を表示します。

## サイドチェイン（Det ページ）

1. **SC SOURCE** で入力元（トラック／リターン／Drum Rack のチェーンなど）を選び、**CHANNEL**（Pre FX / Post FX / Post Mixer）を選びます。
2. **Ext SC** を on にすると外部サイドチェインを使います。デバイスは `live.routing` でそのソースを 3/4 チャンネルへ取り込みます。
3. **FREQ**（＋ **EQ MODE / Q / TILT**）で、検出器を駆動する帯域を選びます。オーディオ出力は変わりません。

## 同期（SYNC）

- SYNC=on で **Live のトランスポートに追従**します。再生中は LFO 位相が頭拍にロックし、停止中は 0 で保持します（ドリフトしません）。
- テンポを変えると LFO レートとディレイ時間が追従します。RATE/TIME の表示は `1/4`、`1/8.`、`1/4T`、`1Bar` などの音符分割になります。

## 注意・制限

- `RATE` と `TIME` は **SYNC を共有**します（両方が同時に Hz/ms ↔ 音符分割へ切り替わります）。
- マッピングは `live.modulate~` のみを使います（`live.remote~` は不使用）。`live.map` のクリックは **手作業**が必要です（Live にヘッドレス API がありません）。
- サイドチェインと Map ページは **Live 12+** が必要です。ルーティングはデバイスを**保存して再追加**しないとリストに現れないことがあります。
- トランスポート同期は Max for Live のグローバルトランスポート（Live 追従）に依存します。Max/Live のアップデート後に確認してください。
