# drummuta — 取扱説明書

**drummuta** は、MIDI クリップと音源（Drum Rack など）の間に挿して、ノートイベントをリアルタイムに加工する Max for Live **MIDI エフェクト**です。間引き（Density）、ベロシティ、移調（Swap）、そして小節単位のフィル（Fill）を、ひとつのデバイスで扱えます。

## セットアップ

- MIDI トラックの、**MIDI クリップと音源の間**に挿します。ノートは加工されてそのまま音源へ渡ります。
- Fill は Live の**トランスポートに同期**するため、再生中に効果を発揮します。

```
[MIDI Clip] ─▶ [ drummuta ] ─▶ [ Drum Rack ] ─▶ 出力
```

## パラメータ

| パラメータ | 範囲 / 初期値 | 説明 |
| --- | --- | --- |
| **DENSITY** | 0–100 % / `100` | ノートオンが残る確率です。ノートオフは常に通ります（音が残りません）。 |
| **VELOCITY** | 0–2× / `1×` | ノートオンのベロシティ倍率です。中央（64）が 1×。 |
| **SWAP** | 0–1 / `0` | 移調量です。`SWAP OFF`（半音）と掛け合わせて使います。0 で無効。 |
| **FILL** | 0–1 / `0` | フィル中に Density を薄め、Swap を持ち上げる強さです。 |
| **SWAP OFF** | -24〜+24 半音 / `0` | 全ノートに加える移調量（半音）です。 |
| **FILL RATE** | 1–16 小節 / `4` | `FILL RATE` 小節ごとの**最後の1小節**でフィルがかかります。 |
| **FILL NOW** | on/off / `off` | 手動でフィルを1回発動します。 |

## 動作

- **Density** — 各ノートオンを確率で間引きます。オフは常に通すので、ノートが残り続けることはありません。
- **Velocity** — ノートオンのベロシティを 0〜2× にスケールします（オフ側は 0 のまま）。
- **Swap** — 各ノートを `round(SWAP OFF × SWAP)` 半音だけ移調します。`SWAP=0` なら無加工、`SWAP=1` で `SWAP OFF` のぶんだけ動きます。
- **Fill** — `FILL RATE` 小節ごとの最後の小節で、Density が `(1 − FILL)` 倍に薄まり、Swap が `FILL` のぶん持ち上がります。フィル中は LED が点灯します。`FILL NOW` で任意のタイミングでも発動できます。

## レシピ

- **ハイハットを疎にする**: `DENSITY 60%`。オフは通るので音は伸びません。
- **アクセントを付ける**: `VELOCITY` を上げて、クリップ側の強弱を強調します。
- **音程を落とす**: `SWAP OFF = -12`、`SWAP` を上げるとタム／ベースが1オクターブ下がります。
- **4小節ごとにフィル**: `FILL RATE 4`、`FILL 0.8`。最後の小節だけ密度が減り、ピッチが動きます。

## 注意・制限

- パッド（4×4）単位のノート選択は**現在ありません**。drummuta はすべてのノートを加工します（将来復活予定）。
- Fill は Live のトランスポート同期です。スタンドアロン Max では Max 側のトランスポートに従います。
